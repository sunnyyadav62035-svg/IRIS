# 🌸 Iris Flower Classification

A Machine Learning classification project developed as part of the **QSkill Artificial Intelligence & Machine Learning Internship 2026**.

## 📌 Project Overview

The objective of this project is to classify iris flowers into three different species based on their sepal and petal measurements.

The three species are:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

The project follows a basic Machine Learning workflow including data exploration, visualization, preprocessing, model training, prediction, and evaluation.

## 🎯 Objectives

* Explore the Iris dataset
* Understand the features and target variable
* Check missing values and duplicate records
* Visualize relationships between features
* Split the dataset into training and testing sets
* Train a classification model
* Evaluate model performance
* Predict the species of a new flower

## 📊 Dataset

The project uses the classic Iris dataset.

The dataset contains measurements for:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The target variable is the Iris species.

## 🛠️ Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 🤖 Machine Learning Model

The project uses **Logistic Regression** for classification.

The dataset is divided into:

* 80% Training Data
* 20% Testing Data

The target labels are encoded using Scikit-learn's `LabelEncoder`.
